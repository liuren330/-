# 类型与风格标签判定表

主题分析阶段先判断信息关系，再判断视觉风格和设计方法。标签可多选，但必须注明主标签及选择理由。

| 维度 | 可选标签（初始词表） | 判定问题 |
|---|---|---|
| 信息组织类型 | 编年型、层级型、编目型、字母表型、地理型、混合型 | 信息单元之间最主要的组织关系是什么？ |
| 内容表达形式 | 文字型、词云图、照片型、插画型、地图型、时间轴、流程图、统计图表、图解型 | 读者主要通过什么形式读取内容？ |
| 视觉风格 | 平面/矢量、照片/纪实、手绘、几何、极简、复古、混合 | 视觉语言呈现什么风格？ |
| 基础设计方法 | ISOTYPE、图标系统、数据驱动排版、摄影叙事、地图叙事、信息分层 | 信息如何被转译为视觉表达？ |
| 媒介/交互 | 静态印刷、长图、网页、滚动叙事、交互仪表板、动态影像 | 最终在哪种媒介中被使用？ |

## 主题分析提示词模板
请基于我提供的选题资料，先拆解主题、受众、核心问题和可用证据。不要直接套用一种图形。请分别判断：①信息组织类型（编年/层级/编目/字母表/地理/混合）；②表达形式（词云、文字型、照片型、地图、统计图等）；③视觉风格（平面、照片、手绘等）；④基础设计方法（是否适合ISOTYPE）；⑤媒介形式。每项给出证据、适用理由、风险和备选方案。对没有数据支持的判断标为假设，并列出需要采集的字段。最终给出主标签+次标签组合建议。
