# 03｜数据搜集

数据来源分三类：

1. 公共数据集：政府开放数据、国际组织、研究机构、开放科学平台；记录下载链接、版本、许可和更新日期。
2. 文本文献：论文、书籍、报告、档案、新闻资料；记录作者、标题、出版信息、页码/段落和引用定位。
3. 自建数据集：实地观察、问卷、访谈、人工编码、传感器或公开网页采集；记录抽样、工具、采集日期、伦理与隐私处理。

来源登记字段建议：source_id、source_type、title、publisher、url_or_reference、access_date、publication_date、license、coverage、notes。

质量控制：检查代表性、缺失、重复、偏差、时间口径、地理边界、单位和数据许可。不得把二手图表读数伪装成原始数据。

建议产出：数据来源登记.csv、文献摘录.csv、采集日志.md及原始文件只读归档目录。
