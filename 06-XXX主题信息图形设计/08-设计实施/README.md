# 08｜设计实施

1. 信息架构与版面草图：确定阅读路径、分区、主次层级和信息密度。
2. 视觉系统：建立网格、色彩、字体、图标、插画/摄影规范和组件库。
3. 图表制作：按已验证的数据映射生成图表，保留可编辑源文件。
4. 版式整合：将叙事段落、数据图形、标题、注释、图例和来源整合。
5. 原型评审：核查事实、数据、阅读路径、可读性与版权。
6. 修订与输出：记录版本、修改理由、输出尺寸、印刷/屏幕规范。
7. 归档：最终文件、源文件、数据版本、字体/图片许可和项目复盘。

交付目录建议：草图、视觉规范、图表源文件、版式源文件、导出文件、评审与修改记录。

每个图形都能回溯到数据字段；每个数字都能回溯到来源；每张图片/字体都完成许可核验；导出文件包含必要图例、单位、来源和日期。
