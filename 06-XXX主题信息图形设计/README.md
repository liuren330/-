# 04｜XXX主题信息图形设计

> 本目录是单个主题项目的可复制工作模板。将“XXX”替换为实际选题名称；每个新选题复制一份目录并重命名为“04-具体主题信息图形设计”。

## 项目目标
围绕一个明确选题，完成从调研、内容分析、数据采集、数据集构建、叙事设计、视觉编码测试到设计实施的完整流程。该目录以设计项目为中心，不预设最终信息图形类型。

## 项目核心原则
- 先理解主题与数据，再决定图形类型和风格，不从预设模板倒推内容。
- “信息组织类型”“视觉风格”“设计方法”“媒介形式”分开标注，可多标签组合。
- 基础数据集一列只放一个字段、一格只放一个原子值；名义、量化、图像和文本字段均可，但不得把多个值塞进同一单元格。
- 每个数据字段保留定义、单位/格式、来源、时间/空间范围、采集日期、清洗规则与缺失值说明。
- 叙事结论必须能回溯到明确的数据字段或文献证据。
- ISOTYPE作为基础设计方法标签，不作为信息图形类型；可与其他类型组合。
