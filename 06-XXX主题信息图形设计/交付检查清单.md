# 项目交付检查清单

- [ ] 前期调研有来源、受众和同类案例证据
- [ ] 主题内容分析完成，并记录大模型建议与人工核验
- [ ] 信息类型、表达形式、视觉风格、设计方法、媒介形式分维度标注
- [ ] 数据来源有链接、机构、许可、时间范围和采集日期
- [ ] 基础数据集每列一个字段、每格一个原子值
- [ ] 数据字典解释字段定义、单位、格式和缺失值
- [ ] 叙事框架中的每个观点都能对应到具体字段或文献
- [ ] 视觉编码说明点线面体、色彩、字体、图像、图表与符号规则
- [ ] 如采用ISOTYPE，明确一个符号代表的数量及重复规则
- [ ] 信息轮盘测试状态与待办事项已标记
- [ ] 设计实施包含草图、原型、评审、修改和最终文件
- [ ] 图像、字体、数据和文献的版权/许可已核查
