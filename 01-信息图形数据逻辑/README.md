## 统一分析维度
每份文档均按以下结构研究：
- A. 基本数据逻辑：决定该类型成立的核心数据结构与关系。
- B. 统计图形与计算方式：使用、借用或改造了哪些统计图形、统计口径和计算方法；若没有统计计算，应明确说明。
- C. 视觉编码：点、线、面、体、符号、文字、色彩、尺寸、位置等如何映射信息。
- D. 数据/信息架构：信息单元、字段、分组、层次、导航与阅读路径。
- E. 视觉叙事架构：如何建立主题、顺序、对比、重点、转折与结论。

## 证据与更新原则
1. 案例图是归纳类型特征的主要证据。没有案例支撑的内容标注为“待案例验证”或“分析假设”。
2. 每个案例需链接到案例库中的原图/来源及分析报告；理论文档只引用，不复制图片。
3. 新案例加入后，先完成案例分析，再更新对应类型的共性、差异、适用条件和反例。
4. 不把单个案例的设计选择直接提升为类型的必要特征。
5. 记录修订日期、依据案例和修改理由，保留不同案例之间的差异。
