# 01｜信息图形数据逻辑

本目录集中管理五种基础信息图形类型的分类资料、概念说明、基础数据集与案例分析报告。各类型目录及其全部现有内容统一归档于本目录。

## 五种基础类型
1. [01｜编年型信息图](./01-编年型信息图/)
2. [02｜层级型信息图](./02-层级型信息图/)
3. [03｜编目型信息图](./03-编目型信息图/)
4. [04｜字母表型信息图](./04-字母表型信息图/)
5. [05｜地理图形型信息图](./05-地理图形型信息图/)

## 归档原则
- 保留各类型目录内原有的概念说明、基础数据集、案例分析报告及设计方法标签。
- 新增同类型资料时，优先放入对应类型目录。
- 跨类型的通用理论、分类标准与方法框架放在本目录根部，并在此处补充导航。
