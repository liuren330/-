# 信息图形类型学研究与案例库

本仓库用于系统整理信息图形类型学知识、典型案例及其数据、统计、视觉与叙事结构。

## 目录导航
- [01 信息图形数据逻辑](./01-信息图形数据逻辑/)
- [02 信息图形类型案例](./02-信息图形类型案例/)（17种表现类型、案例分析与标签体系）
- [03-ISOTYPE信息图](./03-ISOTYPE信息图/)（独立专项：基础设计方法、历史研究、视觉语法与案例）
- [04-Gestalt格式塔视觉组织原则](./04-Gestalt格式塔视觉组织原则/)（视觉感知理论、原则定义、案例分析与设计实践）
- [05-统计图形分析](./05-统计图形分析/)（统计图形、数据结构、统计逻辑与视觉编码）
- [06-XXX主题信息图形设计](./06-XXX主题信息图形设计/)（具体主题项目流程模板）

## 分类与方法边界
1. 01整理信息组织逻辑；02整理表现类型、案例和检索标签。
2. 03研究ISOTYPE基础设计方法，不属于信息图形表现类型，也不计入02的17种类型。
3. 04研究格式塔视觉组织原则，为信息图形及其他视觉设计提供分析依据。
4. 05研究统计图形背后的数据结构、统计逻辑、计算方法、字段映射与视觉编码。
5. 06作为具体主题信息图形设计项目模板。

## 案例研究原则
记录原始出处、作者、发布时间和可访问链接；区分可核实事实、研究者解释与待验证判断。新增案例后同步更新所属类型的概念总文档与案例索引。
