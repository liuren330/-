## 案例研究原则
1. 记录示例图原始出处、作者、发布时间和可访问链接；未经许可不重新分发受版权保护图片。
2. 区分可核实事实、研究者解释与待验证判断。
3. 每个案例按八个维度记录：示例图、分析报告、类型学分类、数据结构、统计图形应用、视觉编码、信息框架、叙事框架。
4. 新增案例后，同步检查并更新所属类型的概念总文档与案例索引。
5. 允许跨类型标注主类型与次级类型，不强行单一归类。

## 命名规范
案例分析报告使用“案例名称-信息图形案例分析报告.md”；图片文件名应包含案例名称、来源/作者和年份。

## 版本维护
新增案例、修订分类标准或调整理论定义时，在对应总文档的修订记录中注明日期、修改内容与关联案例。
