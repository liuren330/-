# 经典案例研究

记录格式塔知觉组织研究中的经典实验、原始图示、出版物和可核验案例。每条记录至少包含研究者、年份、原始出处、研究问题、刺激材料、实验结论、适用边界和来源链接。优先引用原始论文或权威学术综述，尊重图片版权。

## 起点文献
- Wertheimer (1912)：似动现象（phi phenomenon）研究，是格式塔心理学的重要历史起点。
- Wertheimer (1923)：关于知觉组织因素的经典研究。
- Palmer (1992)：共同区域（Common Region）分组原则研究。
- Wagemans et al. (2012)：对经典与较新分组原则、图形—背景组织的系统综述。
