# 词云图：数据结构

| 字段 | 类型 | 含义 |
|---|---|---|
| term | string | 词项/短语 |
| weight | number | 词频或其他权重 |
| count | integer | 原始计数（若适用） |
| category | string | 主题/类别（若适用） |
| color_group | string | 颜色分组（若适用） |
| source | string | 文本来源 |

## 文本处理流程
记录语料范围、分词语言与工具、停用词表、词形归并、短语识别、权重计算、过滤阈值及抽样方法。

## 数据质量
说明重复、歧义、多义词、词频归一化和语料代表性问题。
