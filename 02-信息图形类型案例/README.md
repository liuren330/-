## 文件组织规则
每个类型文件夹内设有README.md与案例/子文件夹；每个案例继续使用案例名称及分析、来源、数据文件。图片放入对应案例的原图/子目录，数据放入data/。

## 双层分类原则
- **表现类型（本目录17类）**：回答案例视觉上属于哪种表现形式。
- **信息组织逻辑（T/H/C/A/G）**：回答信息按什么逻辑组织。
- **标签体系**：记录词云信息图、时间轴、混合图表等跨类别检索特征。
- **方法边界**：ISOTYPE不属于本目录的类型或标签体系；它是独立的基础设计方法专项，统一收录于[03-ISOTYPE信息图](../03-ISOTYPE信息图/README.md)。

## 归档规范
案例文件夹保留自己的analysis.md、source.md、图片与数据。没有原始图片文件时不以参考仓库的图片冒充。
