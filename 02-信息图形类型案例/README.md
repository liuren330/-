## 文件组织规则

每个类型文件夹内设有 `README.md` 与 `案例/` 子文件夹；每个案例继续使用原有案例名称和原有分析、来源、数据文件。此次调整只改变文件夹归属和层级，**不引入参考仓库的案例，不替换或删除你的案例内容**。

## 双层分类原则

- **表现类型（本目录 17 类）**：回答案例“视觉上属于哪种表现形式”。
- **信息组织逻辑（T/H/C/A/G）**：回答案例“信息按什么逻辑组织”。保留在每个案例分析文档中。
- **标签体系**：记录词云信息图、时间轴、混合图表等可检索特征；ISOTYPE 继续作为独立专项项目。

## 归档规范

案例文件夹保留自己的 `analysis.md`、`source.md`、图片与数据。图片应放入对应案例的 `原图/` 子目录，数据放入 `data/`。没有原始图片文件时不以参考仓库的图片冒充。
