# 案例 T-006｜美国遣返数据复合信息图（Deportations from the US）

## B. 图形特性

### 1. 信息目标与读者
展示美国移民遣返/返还政策的长期变化，比较不同总统任期之间的执法规模，并提醒读者不要只从单一总统任期理解长期政策趋势。

### 2. 内容单元与数据关系
当前可核实的图面说明包含：
- 时间范围：1901—2016年；
- 总体指标：按总统任期汇总的被移除或被遣返/返还人数；
- 总统任期：按任期排列的总统姓名与年份；
- 统计口径：Removal 与 Returns 两类执法结果，需按图例区分。
相关研究资料对图面描述为：以美国地图作为主体视觉背景，配合顶部各总统任期的数字总量和条形标记。精确图表组件、数值和图例应以原图高清版本核对。

### 3. 布局与构图
地图承担地理主题锚点，时间维度则通过总统任期序列展开；标题、总统姓名/任期、数字汇总和条形图形成辅助阅读层。地图与时间统计在同一画面并置，使空间对象（美国）与历史政策变化相互关联。

### 4. 优势、局限与适用场景
- 优势：将地理背景、政治任期与历史数量变化放在同一视觉叙事中；通过口径区分避免把不同执法结果混为一谈。
- 局限：地图面积不代表遣返人数；总统任期长度不一，若不进行年均化，任期总量不能直接解释为执法强度；Removal 与 Returns 的定义差异必须保留。
- 适用：需要将政策地理范围与长期时间趋势并置解释的公共政策/数据新闻信息图。

## C. 制作方法与流程

### 可确认事实
- Awards 页面将作品署名为 Marcelo Duhalde - South China Morning Post。
- Awards 页面描述：被移除人数在数十年间持续增加，作品希望讨论当届总统立场是否构成政策根本转变。
- 研究资料中可见图面标题“Total immigrants removed or returned, by presidential term (1901–2016)”及 Removal / Returns 术语说明，并描述了美国地图和按总统任期组织的数字/条形信息。

### 制作流程重建（分析推断）
1. 收集历史移民执法记录，并按总统任期归并。
2. 对 Removal 与 Returns 的定义进行区分，统一时间范围与统计单位。
3. 将每个总统任期的记录聚合为总量；若比较执法强度，还需另算年度平均值，不能直接以任期总量替代。
4. 以美国地图建立地理语境，将时间序列/条形数据安排在地图周围或上方。
5. 用标题、定义说明和来源标注交代统计口径。
6. 对总统任期边界、年份覆盖和历史数据缺口进行校验。

## D. 视觉编码
- **地理轮廓/空间位置**：美国地图用于指示政策发生的地理范围，不代表数值大小。
- **横向时间顺序**：总统任期按年份顺序排列，承担历史主索引。
- **条形长度/数字标签**：表达总统任期汇总的移除/返还人数；需结合图例确定条形对应的指标。
- **颜色**：若以不同颜色区分 Removal 与 Returns，应按原图图例读取；不能仅凭色彩猜测含义。
- **文字**：总统姓名、任期年份、主标题及术语定义构成解释系统。
- **视觉层级**：地图提供主题锚点，任期序列和数字承担比较，术语说明负责界定数据口径。

## E. 视觉叙事
- **入口**：从“美国遣返”主题与地图建立地理语境。
- **展开**：沿总统任期从1901年推进到2016年，观察长期数量变化。
- **对比/转折**：比较不同总统任期的总量，并将历史长期趋势置于单届政府的政治表态之外。
- **结论**：作品强调遣返人数上升具有更长的历史背景，不能简单归因于某一届政府。
- **叙事边界**：历史总量与执法强度不是同一指标；任期长短、人口基数、政策定义及统计口径都会影响比较。

## F. 基础数据集
- **数据集名称 / 文件**：原始作品所用历史移民执法数据，具体版本未确认。
- **字段线索**：年份、总统任期、Removal 数量、Returns 数量；可能还需来源机构及定义字段。
- **来源与许可**：作品页未提供可直接下载的完整底层数据；官方历史统计可能存在不同口径版本，尚未验证与图面逐项一致。
- **处理状态**：未上传数据文件；不根据图面数字反向编造数据。
- **后续要求**：取得原图来源注释后，逐项追溯至原始政府统计表，记录口径、时间覆盖和修订日期。

## G. 归纳与复用
- 地图+时间统计可同时回答“在哪里”与“如何随时间变化”，但地图不应被误读为数量图。
- 多指标政策数据必须显式定义指标，尤其是概念相近但统计口径不同的类别。
- 对任期长度不同的对象，区分总量比较与年均强度比较。
- **待验证**：原图全部图层、准确数值、官方数据源版本、地图底图来源和软件工具。
