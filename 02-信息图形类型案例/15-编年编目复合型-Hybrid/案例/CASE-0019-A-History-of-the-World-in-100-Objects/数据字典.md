# 数据字典｜CASE-0019

- 数据性质：项目元数据与交互分类维度，不是完整100件物品记录。
- 记录粒度：每行一个独立项目字段或一个筛选维度。
- 来源：BBC项目档案、Smithsonian Libraries书目记录。

| 字段 | 类型 | 含义 | 限制 |
|---|---|---|---|
| record_id | string | 唯一记录标识 | 项目元数据与筛选项分别编号 |
| field | string | 字段名称 | 项目年份、数量、作者、筛选维度等 |
| value | string/number | 单一字段值 | 每个单元格只放一个值 |
| unit | string | 单位或值类型 | year、objects、category等 |
| source | string | 来源位置 | BBC或Smithsonian |
| status | string | 核验状态 | verified或approximate |

筛选维度 location、theme、culture、size、colour、material 已拆成独立行，避免在单元格中塞入多值。完整对象表需一行一件物品；年代允许区间与约数，不能假造精确日期。
