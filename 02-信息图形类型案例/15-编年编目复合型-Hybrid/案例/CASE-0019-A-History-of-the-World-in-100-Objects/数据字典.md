# 数据字典｜CASE-0019

- 数据性质：项目元数据与交互分类维度，不是完整100件物品记录。
- 记录粒度：每行一个项目级字段。
- 来源：BBC项目档案、Smithsonian Libraries书目记录。

| 字段 | 类型 | 含义 | 限制 |
|---|---|---|---|
| project_year | integer | 项目年份 | 公元年 |
| object_count | integer | 广播系列对象数量 | 100件 |
| chronological_start | integer | 历史范围起点 | 约两百万年前 |
| chronological_end | integer | 项目覆盖终点 | 2010 CE |
| creator | string | 系列撰写／讲述者 | Neil MacGregor |
| exploration_facets | string | 可浏览分类维度 | 当前作为复合值保留在项目元数据；逐对象数据应拆成关联表 |

完整对象表需一行一件物品；年代允许文本区间与约数，不能假造精确日期。
