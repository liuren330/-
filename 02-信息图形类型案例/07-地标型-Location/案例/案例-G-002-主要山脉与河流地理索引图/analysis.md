# 案例 G-002｜主要山脉与河流地理索引图

- **主类型**：地理图形信息图形
- **辅助逻辑**：字母索引、分类表格、地理对象目录
- **图面标题**：图面顶部可辨识为关于世界主要山脉/河流高度或长度的英文标题；具体原文因分辨率不足待核实。
- **图像记录**：用户上传的古典风格地理图；作者、出版物、年代与来源待核实。

## 一、客观观察

画面主体是一座以透视/立体方式表现的山地地形，山峰沿空间纵深排列，山脊、山谷和水系以线描与阴影表现。山体周围及上方有大量竖向文字标注，指向具体地理对象或名称。页面底部设置多列信息表格，并可辨识“Alphabetical Index”字样，说明另有按字母顺序组织的地理名称索引。整体将地貌图、地理名称标注和目录表格整合在同一版面。

## 二｜A｜基本数据逻辑

- **核心空间对象**：山峰、山脉、山脊、山谷及河流/水系（具体条目需高清原图核对）。
- **核心关系**：地理对象在山地空间中的相对位置、相互邻近、地形高低与可能的水系联系。
- **辅助索引**：底部字母索引和多列表格用于按名称查找对象，并将名称与图中地理对象对应。
- **数据模型推导**：`GeoFeature(feature_id, name, feature_type, map_position, elevation_or_length, index_key, description)`；`IndexEntry(index_key, feature_id, table_column, reference_mark)`。这是基于图面结构的抽象模型，不代表原始数据表。
- **主类型判断**：主体图像以山地地貌和地理对象的空间位置为组织核心；字母索引虽明确存在，但属于辅助检索层。因此主类型为地理图形，辅助类型为字母表/目录索引。

## 三｜B｜地图表达与计算方式

- **地形透视图/地貌示意图**：以立体山体表现山峰、山脊和谷地的相对空间形态。
- **地形晕渲与阴影线描**：通过明暗、纹理和轮廓线塑造高低起伏。
- **地理对象标注**：名称沿地形对象或画面边缘布置，建立文字与地图位置的对应。
- **索引表格**：以表格和字母序列支持名称查找与信息比对。
- **潜在定量维度**：标题似乎涉及山脉高度与河流长度等度量，但受图像分辨率限制，无法可靠转录具体指标、单位或数值。不得据此补造数据。
- **计算方式**：当前图面更偏向地理对象展示与索引检索；若要复原其定量逻辑，需取得高清原图并核实各列字段、单位和数据来源。

## 四｜C｜视觉编码

- **体/形态**：山体透视轮廓和峰顶高度差形成地貌主视觉。
- **面**：山体阴影、坡面明暗和纹理区分不同地形面。
- **线**：山脊线、谷线、河流线及引导标注线建立空间关系。
- **点/符号**：峰顶或地理对象的定位符号用于指认具体条目（需高清图确认符号规则）。
- **色彩**：以纸张底色、灰褐色山体和少量黄色标记形成古典制图风格；黄色标记的准确语义待核实。
- **文字**：竖向标注沿图幅边缘排列；底部表格承载结构化条目；字母索引提供检索入口。
- **辅助编码**：表格列、字母分组与地图位置之间应存在可追溯的交叉引用，但当前缩略图无法完全辨认其编号/符号规则。

## 五｜D｜数据/信息架构

1. 标题与地理主题范围。
2. 主体山地地貌图。
3. 山峰、山脉、河流等对象名称标注。
4. 可能的高度/长度等属性字段（具体字段待高清原图核实）。
5. 底部结构化表格。
6. Alphabetical Index 字母索引。
7. 地图对象与表格/索引之间的交叉查找关系。

## 六｜E｜视觉叙事架构

读者先通过主体山体建立地貌整体印象，再沿山峰、山脊和谷地观察地理对象的空间分布；随后查阅地图周边名称标注，最后使用底部表格和字母索引检索具体条目。叙事路径为“地貌总览—空间定位—对象识别—表格核对—字母索引检索”。

## 七｜可迁移设计方法

1. 将地形形态作为主视觉，同时用标注层精确指认地理对象。
2. 对对象数量较多的地图，可将目录/字母索引与主地图结合，降低查找成本。
3. 通过稳定的编号、字母或引线建立地图与表格的双向索引。
4. 对高度、长度等定量属性，需明确单位、排序规则和数据来源。
5. 让索引服务于地图检索，不要让表格脱离地图空间对象而成为独立清单。

## 八｜待核实

- 原图完整英文标题、作者、年代、出版物和出处。
- 地图所列对象究竟是主要山脉、山峰、河流还是多类地理实体。
- 表格字段、单位、具体数值和字母索引的完整内容。
- 地图标注与表格条目之间采用何种编号/符号交叉引用。
- 黄色标记的含义及其是否对应某一类地理对象。

## 十｜01 类别与 02 标签归档

- **01 主类别**：地理图形型（G）。地貌形态及地理对象的空间位置是主导组织原则。
- **次要特征**：字母表/目录索引、表格编目。
- **02 现有标签**：待核对正式标签清单；候选描述为“地貌透视图 / 地图—索引复合 / 字母目录”，暂不登记为正式标签。
- **分类依据**：主体是空间地貌与地理对象定位，字母索引仅辅助查找名称。

## 十一｜制作方法与流程（推测与观察分开）

1. 采集地理对象名称、类型、位置及可能的高度/长度属性（推测，字段仍待高清原图核实）。
2. 按地理空间关系组织山峰、山脉、河流等对象（推测）。
3. 绘制或整理地貌透视图，以轮廓、阴影和纹理表现地形（图面可观察）。
4. 将对象名称布置在地图附近，并通过编号、引线或索引关系与底部表格关联（部分可观察，具体交叉引用规则待核实）。
5. 建立字母索引及表格字段，校验名称、数值、单位和地理位置（推测）。

原始制图软件、测绘数据来源、投影方式和具体计算过程未知。
