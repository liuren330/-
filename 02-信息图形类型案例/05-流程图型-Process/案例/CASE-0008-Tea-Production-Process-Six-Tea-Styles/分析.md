# CASE-0008｜Tea Production Process｜六类茶加工流程图

## 元数据
- 作者／机构：美国茶产业综述论文作者团队（见论文署名）
- 年份：2022
- 原始来源：https://pmc.ncbi.nlm.nih.gov/articles/PMC9538180/
- 主表现标签：05｜流程图型（Process）
- 五大基础类型唯一主归属：**编年型（T）**
- 原图：官方／作者页面外链；本地未存第三方图像。

## 作品概述与证据边界
论文Figure 1以流程图总结六种茶的加工过程。图注给出一个关键图例规则：实线表示始终使用的加工步骤，虚线表示有时或可选使用的步骤。正文说明乌龙茶和红茶在萎凋期间或之后会进行揉捻、压碎或扭曲叶片的破壁处理，随后进行进一步干燥。

**主归属：编年型（T）**。茶叶加工由步骤依赖关系构成，先后顺序是理解加工过程的必要条件；不同茶类形成分支路径。流程图是这一顺序结构的可视化。

### A｜基本数据逻辑
最小单位是“茶类—加工步骤—前置／后续关系”。字段建议tea_style、step_id、step_name、sequence_order、edge_type、optional_flag、source。图中实线与虚线不是数值，而是必经与可选关系。

### B｜统计图形与计算
无须统计图表。核心是有向流程关系、条件分支和步骤是否可选。不可把节点间距解释为加工时长，除非另有时间数据。

### C｜视觉编码
节点代表加工阶段；实线表示必经步骤；虚线表示可选步骤；箭头方向表示工序推进。若不同茶类共用节点，可用汇合／分支表示共享与差异，必须保留图例。

### D｜数据与信息架构
推荐拆成步骤表与边关系表：步骤表一行一个茶类中的加工步骤；关系表一行一条有向连接，并记录edge_type。当前CSV只记录图注明确的必选／可选编码和正文可核验的工序，不重建整张六茶流程图。

### E｜视觉叙事
从茶叶原料开始，沿分支路径观察不同茶类如何通过不同的加工组合形成；实线与虚线帮助读者区分必要步骤和可选步骤。图形的重点不是单条线性流程，而是多茶类之间的共享步骤与分支差异。

### 制作与复核
依据论文图1转录节点和边→按茶类分组→核对每条边的必经／可选状态→绘制流程→用线型图例编码→请茶学文献复核加工逻辑。论文为开放获取研究来源；本仓库只链接原图，不复制期刊图像。

## 质量复核状态
当前CSV为图注及正文可核验的流程关系样例，不是完整Figure 1逐节点数据表。六类茶的全部节点和连线仍需逐图转录；节点间距不代表加工时长。

## 可迁移设计原则
1. 先确定作品主导的信息关系，再判断市场表现标签；不能以视觉风格替代数据逻辑。
2. 每个视觉通道都要对应明确语义；示意元素、统计编码和编辑性修辞要分开说明。
3. 图面转录、作者文字说明、原始数据和分析推断必须分层记录。
4. 缺失数据保持缺失，不用图像估值或模型猜测补齐。
