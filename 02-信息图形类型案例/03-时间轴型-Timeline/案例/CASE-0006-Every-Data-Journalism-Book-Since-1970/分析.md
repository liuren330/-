# CASE-0006｜Every data journalism book since 1970｜1970—2012数据新闻图书时间轴

## 元数据
- 作者／机构：Henk van Ess（图形）；The Guardian Datablog（发布）
- 年份：2012
- 原始来源：https://www.theguardian.com/news/datablog/2012/may/11/data-journalism-book
- 主表现标签：03｜时间轴型（Timeline）
- 五大基础类型唯一主归属：**编年型（T）**
- 原图：官方／作者页面外链；本地未存第三方图像。

## 作品概述与证据边界
作品以1970—2012年间的数据新闻相关书籍为时间索引，由Henk van Ess制作并由The Guardian Datablog发布。发布页将领域演变概括为 precision reporting、computer assisted reporting、data journalism 三个术语阶段，并链接交互时间轴与视频。

**主归属：编年型（T）**。年份是主索引，书籍作为时间节点／条目附着在时间轴上。编目属性（书籍目录）是辅助组织方式，不改变时间主轴。

### A｜基本数据逻辑
最小单位应为一条书目记录：book_id、title、author、publication_year、topic_phase、source_url。当前官方发布页只核验了总体时间范围、作者和三个阶段术语，未能在页面文本中恢复完整书目条目。

### B｜统计图形与计算
核心表现是交互时间轴，不是统计图表。可计算出版物数量按年份或十年分布，但只有在取得完整书目数据后才执行；不能从页面描述猜测每年书籍数量。

### C｜视觉编码
时间位置编码出版年份；书名与书目内容承担文本标签；术语阶段用于解释领域概念的变化。时间轴的节点间距是否按真实年份比例，应通过交互原图复核，不能仅凭“timeline”一词推断比例尺。

### D｜数据与信息架构
书目主表建议一行一本书；年份字段使用整数；阶段归属单独存储并允许空值／多标签。当前CSV仅为可核验元数据和阶段术语索引，不是完整书目表。

### E｜视觉叙事
从1970年起点向2012年终点推进，沿时间轴观察数据新闻知识体系及出版物的发展；阶段术语提供语义解释，书目条目为演变提供具体证据。

### 制作与复核
取得交互时间轴→提取所有书目节点→核对出版年份与书名→按统一时间尺度布置→用阶段标记解释术语变化→复核链接和重复书目。发布页明确作者和时间范围，足以作为来源档案；本仓库不复制第三方时间轴图像。

## 质量复核状态
Guardian发布页说明完整时间范围和作者，但没有在可访问文本中提供完整书目行。当前CSV只记录官方可核验的时间边界及阶段术语，不冒充原始书目数据。

## 可迁移设计原则
1. 先确定作品主导的信息关系，再判断市场表现标签；不能以视觉风格替代数据逻辑。
2. 每个视觉通道都要对应明确语义；示意元素、统计编码和编辑性修辞要分开说明。
3. 图面转录、作者文字说明、原始数据和分析推断必须分层记录。
4. 缺失数据保持缺失，不用图像估值或模型猜测补齐。
