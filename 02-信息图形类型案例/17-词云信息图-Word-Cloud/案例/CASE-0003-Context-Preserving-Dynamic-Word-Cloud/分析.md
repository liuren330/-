# CASE-0003｜Context-Preserving, Dynamic Word Cloud Visualization

## 元数据与研究边界
- 作者：Weiwei Cui、Yingcai Wu、Shixia Liu、Furu Wei、Michelle X. Zhou、Huamin Qu
- 发表信息：IEEE Computer Graphics and Applications，2010，Vol. 30(6)；论文页面同时提供 Pacific Visualization 2010 会议版本
- 原图定位：论文 Figure 1（系统概览）
- 主表现标签：17｜词云信息图
- 五大基础类型唯一主归属：**编年型（T）**
- 辅助表现特征：趋势曲线 + 五个时间点词云快照 + 交互式探索
- 数据边界：当前 CSV 只记录 Figure 1 中五个快照的日期、子图编号和来源定位。它不是原始语料、词项清单或词频表；未提供的词频和显著性数值不作推算。

## 作品与设计目标
该研究针对静态词云难以呈现文本集合随时间演化的问题，提出把整体趋势曲线与多个时点的词云结合。趋势曲线展示文档集合内容显著性的时间变化；在曲线上选取若干高显著性时点，再分别显示对应词云。作者使用几何网格与自适应力导向模型布局词云，以强调相邻词云之间的语义连贯性和空间稳定性。

Figure 1 的五个快照日期为 1995年5月、1998年10月、2000年8月、2005年9月和2007年6月。上方趋势视图以时间为横轴、词云显著性为纵轴；下方五个词云 (a)–(e) 是选定时点的内容快照。图中词项可观察到早期计算机、软件和操作系统语汇，随后出现音乐播放器、数字音乐，再到 iPhone、移动通信等内容变化。这是基于图像可见词项的定性观察，不代表对原始语料的重新统计。

## 五大基础类型主归属判断
**主归属：编年型（T）。**
1. 趋势图横轴明确编码时间。
2. 五个词云快照分别对应不同时间点，主要任务是比较同一文档集合在时间维度上的语义演化。
3. 词云是各时间点的内容摘要，语义布局服务于跨时点比较，不是严格的上下位分类树。
4. 因此主导信息关系是时间变化；词云只是市场化表现形式标签。

## A｜基本数据逻辑
- 原始对象：带有时间戳的文档集合。
- 分析对象：各时间点具有代表性的关键词及其显著性。
- 最小系统记录单位应为“时间点—关键词”，但论文当前公开图中没有完整原始语料和逐词数值。
- 本档案 CSV 暂以五个“时间点—词云快照”作为记录单位，准确记录图中标注的日期；词项级数据留待逐图人工转录，不以猜测补齐。

## B｜统计图形与计算
- 趋势曲线：概览内容显著性随时间的变化。
- 词云：在选定时点展示代表性关键词。
- 论文方法以条件信息量等信息论指标估计动态词云显著性；不等同于简单词频。
- 作者说明高显著性时间点用于选取词云快照；本案例不从曲线像素反推数值。

## C｜视觉编码
| 视觉通道 | 信息含义 | 可观察证据与边界 |
|---|---|---|
| 横向位置 | 时间 | 趋势曲线横轴为时间 |
| 曲线纵向位置 | 词云显著性 | 论文图注说明纵轴为显著性；没有可供转录的精确数值表 |
| 词语内容 | 代表性关键词 | 五个快照展示各时点的代表词 |
| 文字大小 | 词项重要性提示 | 可见大小差异，但不从图像面积反推精确频率 |
| 词语背景色 | 词项在相邻时间点的出现行为 | 紫色表示仅当前时点出现；红色表示也出现在后续时点；蓝色表示刚在前一时点出现；无底色表示前后时点均出现 |
| 多快照序列 | 时间演化 | (a)–(e) 对应五个明确日期 |

## D｜数据与信息架构
- 原始系统逻辑：带时间戳的文档 → 文本分析 → 代表关键词及显著性 → 时间趋势视图 → 选定时间点词云。
- 当前 CSV 是五行的快照索引表；每行一个词云子图，每列一个时间/来源属性。
- 当前未创建词项级频率表，因为论文图中未提供可直接读取的精确词频、显著性数值或原始文档数据。
- 后续若要构建词项级表，必须从 Figure 1 原图逐词人工转录，并标注 panel、词项、可见字号等级（若定义可靠）及人工复核状态；不可伪造频次。

## E｜视觉叙事架构
1. 先看趋势曲线，理解整体内容显著性的时间变化。
2. 沿时间轴定位五个被选中的高显著性时点。
3. 阅读对应词云，观察该时点的代表关键词及语义聚类。
4. 横向比较相邻词云，识别持续词、新出现词和消失词。
5. 通过背景色和稳定布局帮助用户追踪词项的时间行为，降低跨时点重新定位成本。

## 可复用设计策略
- 不要只把多个静态词云并排；应为跨时间比较保留稳定的空间参照。
- 将全局趋势视图与局部词云快照组合，兼顾宏观变化与局部词项。
- 使用背景色编码词项在前一时点、当前时点、后一时点的出现关系，并提供图例。
- 词频、文档频次、条件信息量意义上的显著性是不同指标，不能互相替代。
- 数据不足时只记录可核验的时间点与视觉规则，不推测原始数值。

## 局限与复核
- 当前数据表只有五个快照日期，不包含原始实验语料或词项级数值。
- 当前案例可用于分析动态词云的时间结构、视觉编码和布局策略，不能用于精确复现作者算法或重建原图。
- 原图为第三方学术出版物内容，本仓库只保留官方论文链接，不上传论文图像。

## 理论回写
本例说明词云并非天然属于编目型：当作品的主要叙事由时间变化驱动、词云作为时间切片时，应以编年型作为基础主归属，词云仅作为市场表现标签。
