# 数据字典｜CASE-0003

## 文件说明
- 文件：基础数据集.csv
- 数据性质：论文 Figure 1 五个词云快照的元数据索引
- 来源：Cui et al., Context Preserving Dynamic Word Cloud Visualization, Figure 1
- 记录粒度：每行一个词云快照
- 记录数：5；字段数：6
- 不包含：原始文档语料、词项级词频、条件信息量数值、字号数值或坐标

## 字段定义
| 字段 | 类型 | 含义 | 单位／口径 |
|---|---|---|---|
| time_step | string | 快照标识 a–e | Figure 1 子图编号 |
| cloud_id | string | 词云子图名称 | Figure 1(a)–(e) |
| displayed_date | string | 图中标注日期 | YYYY-MM |
| source_location | string | 图像来源定位 | Figure 1 |
| transcription_status | string | 转录状态 | 日期已从图中核验 |
| notes | string | 数据限制 | 明示无原始数值 |

## 数据限制
1. 五个日期由论文 Figure 1 趋势图中的标注读取：1995-05、1998-10、2000-08、2005-09、2007-06。
2. 当前 CSV 不含词项级数据；不能据此计算词频、词项变化率或显著性。
3. 后续词项转录必须单独建表，且保留人工复核状态；不得将字号估计写成精确频率。
4. 该表用于索引案例中的时间快照，不足以复现作者的实验数据或算法。
