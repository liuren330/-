# 数据字典｜CASE-0003

## 文件说明
- 文件：基础数据集.csv
- 数据性质：论文 Figure 1 图注中列举的关键词转录表
- 来源：Cui et al., Context-Preserving, Dynamic Word Cloud Visualization, Figure 1 caption
- 记录粒度：每行一个“时间快照—图注词项”记录
- 当前记录：五个快照的词项列表；不是原始文档语料，也不是完整词频数据
- 字段数：6

## 字段定义
| 字段 | 类型 | 含义 | 单位／口径 |
|---|---|---|---|
| time_step | string | 快照标识 a–e | 论文 Figure 1 子图编号 |
| cloud_id | string | 词云子图名称 | Figure 1(a)–(e) |
| caption_sequence | integer | 词项在图注列举顺序中的序号 | 从 1 开始；不代表频率排名 |
| term | string | 图注明确列出的关键词 | 保留原文大小写及重复列举 |
| source_location | string | 来源位置 | Figure 1 caption |
| extraction_note | string | 转录说明 | 明示该行无数值频率 |

## 数据限制
1. caption_sequence 只表示图注列举顺序，不是字号、词频或重要性排序。
2. 论文图注未提供词频、TF-IDF、显著性值、词项坐标或原始语料，故 CSV 不含这些字段。
3. 五个快照之间重复出现的词项不去重，因为重复出现可用于追踪跨时点持续性。
4. 本表用于解释图注公开内容及构建可审计的最小数据记录，不足以精确复刻原图。
