# 字母表型信息图形案例总览（Alphabet / Symbol-System Infographics）

**工作定义**：以一套约定的离散符号单元作为组织与识别基础。符号可为字母、字符、数字或具有稳定含义的图形符号；通过固定、循环或分区索引规则组织条目。此定义为迭代工作定义，后续案例继续验证边界。

## 阶段性观察

- 字母表型不局限于拉丁字母 A—Z；在本项目当前工作定义中，也纳入具有约定含义和稳定映射关系的图形符号系统。
- 符号可作为条目索引、类别标记或主题模块入口。
- 排列方式可以是线性、循环、径向或网格；关键是符号系统承担信息组织功能。
- 环形布局本身不自动构成字母表型；需同时确认符号集合及其索引/映射规则。
- 若符号只作装饰，不参与条目识别和信息导航，应标为装饰元素而非核心编码。

## 入库分类与分析规范（统一口径）

- **01｜五大类别**：字母表型（A）。个案必须以整体主导的信息组织逻辑判定主类别；出现多种结构时，记录主类别与次要/混合特征，不得新增一级类别。
- **02｜现有标签**：待确认：字符索引/符号系统/循环符号表等可作为细分标签候选，须核对现有标签表。 未核实标签清单前，不将临时描述冒充正式标签；个案记录须填写标签及理由，未知时明确标注待确认。
- **图形特性**：记录信息目标、受众、内容单元、布局、构图、色彩、字体、图形语法、信息层级、信息密度与适用场景。
- **制作方法与流程**：按资料/数据采集 → 清洗整理 → 分类排序/统计计算 → 图形形式选择 → 视觉编码映射 → 版面设计 → 校验输出梳理；区分图面可确认事实与推测。
- **视觉编码**：说明位置、长度、角度、面积、颜色、形状、方向、纹理、连接、空间位置、尺度、文字/符号分别映射何种字段及其表达关系。
- **视觉叙事**：说明主题、阅读入口与路径、信息展开顺序、对比/转折、视觉焦点、节奏及结论传达。
- **基础数据集**：能获取且许可允许时上传至个案目录 `data/`；记录来源、格式、字段、处理步骤及视觉映射。不可获取时标注原因，不得编造或上传受限数据。
