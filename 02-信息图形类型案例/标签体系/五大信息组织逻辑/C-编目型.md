# 编目型信息图形案例总览（Catalog Infographics）

**工作定义**：以一组可识别的条目为基础，围绕共同字段进行索引、分类、排序、计数和多维比较。条目之间不必存在从属关系；时间、地理、职业、语言等通常作为条目的属性维度。

## 阶段性观察

- 编目对象可以是人物、机构、出版物或其他具有共同字段的条目集合。
- 条目编号/名称是跨多个图表视图的身份锚点；多视图应共享稳定 ID。
- 时间可以作为条目属性或索引，不会自动使主类型变成编年型。
- 多维编目可以组合名录、统计图、矩阵和流向图；名录负责识别条目，统计图负责比较属性，流向图负责呈现分类映射。
- 颜色、符号、位置、面积和流带宽度必须有明确图例及计量口径。
- 不应把视觉强调、装饰面积或未经说明的流带宽度误读为定量事实。

## 入库分类与分析规范（统一口径）

- **01｜五大类别**：编目型（C）。个案必须以整体主导的信息组织逻辑判定主类别；出现多种结构时，记录主类别与次要/混合特征，不得新增一级类别。
- **02｜现有标签**：待确认：名录/多维编目/索引矩阵等可作为细分标签候选，须核对现有标签表。 未核实标签清单前，不将临时描述冒充正式标签；个案记录须填写标签及理由，未知时明确标注待确认。
- **图形特性**：记录信息目标、受众、内容单元、布局、构图、色彩、字体、图形语法、信息层级、信息密度与适用场景。
- **制作方法与流程**：按资料/数据采集 → 清洗整理 → 分类排序/统计计算 → 图形形式选择 → 视觉编码映射 → 版面设计 → 校验输出梳理；区分图面可确认事实与推测。
- **视觉编码**：说明位置、长度、角度、面积、颜色、形状、方向、纹理、连接、空间位置、尺度、文字/符号分别映射何种字段及其表达关系。
- **视觉叙事**：说明主题、阅读入口与路径、信息展开顺序、对比/转折、视觉焦点、节奏及结论传达。
- **基础数据集**：能获取且许可允许时上传至个案目录 `data/`；记录来源、格式、字段、处理步骤及视觉映射。不可获取时标注原因，不得编造或上传受限数据。
