# 层级型信息图形案例总览（Hierarchical Infographics）

**工作定义**：以包含、从属、分类分支或由整体到局部的关系组织信息。案例判断以主导信息关系为准；内容中出现年代、地理或数量，不自动改变其层级型属性。

## 阶段性观察

- 年代可以作为上位分类节点；具体时期及其下属内容构成下位层级。
- 侧栏标签与主体图像横向对齐，可以明确表达“类别—内容”的归属关系。
- 横向分区既可以承担分组边界，也可以组织每个类别的图文内容。
- 画面出现时间先后，并不意味着它必然是编年型；需判断时间刻度/事件序列是否主导信息组织。
- 插画数量、分区面积和场景大小不应在缺少定量依据时被解释为数量或权重。

## 入库分类与分析规范（统一口径）

- **01｜五大类别**：层级型（H）。个案必须以整体主导的信息组织逻辑判定主类别；出现多种结构时，记录主类别与次要/混合特征，不得新增一级类别。
- **02｜现有标签**：待确认：层级树/分类分层/整体—局部等可作为细分标签候选，须核对现有标签表。 未核实标签清单前，不将临时描述冒充正式标签；个案记录须填写标签及理由，未知时明确标注待确认。
- **图形特性**：记录信息目标、受众、内容单元、布局、构图、色彩、字体、图形语法、信息层级、信息密度与适用场景。
- **制作方法与流程**：按资料/数据采集 → 清洗整理 → 分类排序/统计计算 → 图形形式选择 → 视觉编码映射 → 版面设计 → 校验输出梳理；区分图面可确认事实与推测。
- **视觉编码**：说明位置、长度、角度、面积、颜色、形状、方向、纹理、连接、空间位置、尺度、文字/符号分别映射何种字段及其表达关系。
- **视觉叙事**：说明主题、阅读入口与路径、信息展开顺序、对比/转折、视觉焦点、节奏及结论传达。
- **基础数据集**：能获取且许可允许时上传至个案目录 `data/`；记录来源、格式、字段、处理步骤及视觉映射。不可获取时标注原因，不得编造或上传受限数据。
