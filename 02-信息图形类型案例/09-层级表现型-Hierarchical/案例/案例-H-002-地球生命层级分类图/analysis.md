# 案例 H-002｜Ontwikkeling van het leven op aarde：地球生命层级分类图

- **归属类型**：层级型信息图形（主类型）；编年信息为辅助组织维度。
- **来源记录**：用户上传图片，图面荷兰语标题为 “ONTWIKKELING VAN HET LEVEN OP AARDE”（地球生命的发展）。作者、原始出版物、出处及发布日期尚未核实。
- **图像记录**：原始上传文件名 `2(1).jpg`，尺寸 528 × 717 px；本案例分析基于当前可见图像。
- **主题范围**：通过地质年代大类、具体时期及对应生命/生态场景，展示地球生命知识的分组结构。

## 一、客观观察

画面为纵向矩形版式。左侧浅蓝色栏标出较大的地质年代分组以及更细的时期名称；右侧以横向插画场景呈现对应时期的生物群像和生态环境。各横向区域与左侧标签对齐，形成稳定的“分类标签—对应内容”关系。

画面有从早期到晚期的顺序，但左侧栏同时呈现上位年代分组与下位时期，右侧插画是各分组下的内容说明。主要阅读方式是识别分组及其所包含的生命场景，而不是读取精确时间间隔或事件节点。

## 二｜A｜基本数据逻辑

- **主导逻辑**：层级分类与包含关系。较大的地质年代分组包含若干具体时期，每个时期对应一组代表性生物和生态场景。
- **层级结构**：地球生命主题 → 地质年代大类 → 具体地质时期 → 对应生命类别/生态场景。
- **辅助逻辑**：各分组和时期在地质历史上具有先后顺序，但画面没有呈现可确认的连续比例时间刻度。
- **内容关系**：左侧标签是分类索引，右侧场景是其下属内容；横向对齐强化从属/对应关系。
- **推测的数据模型**：`geological_group → period → life_scene(organism_groups, habitat)`。这是根据版面结构提出的分析模型，不代表原始资料表。

## 三｜B｜统计图形与计算方式

- 主要借用分层分类表、分组矩阵和图文对照结构。
- 左栏通过分组、缩进/分段和标签区分上位年代与具体时期；右侧横向图像带提供对应的内容样本。
- 未观察到数量坐标、频数、比例或可确认的定量统计图形。
- 各分区高度不能直接解释为真实地质年代持续时间；若需要按持续时间比较，必须补充年代起止数据并建立明确比例尺。

## 四｜C｜视觉编码

- **位置**：左侧窄栏固定承担分类导航，右侧大面积插画呈现对应类别内容；水平对齐表达标签与内容的对应。
- **分区/边界**：横向分隔线区分各个具体时期；左侧更大的分组标签将多个时期归并为上位类别。
- **色彩**：浅蓝色导航栏与主体插画形成区域区分；色彩主要用于版面分区，不应推断为数量编码。
- **插画符号**：生物群像和生态环境是各分类单元的具象说明，不代表个体数量或统计权重。
- **文字**：左侧标签承担分类命名，主标题建立整体主题；主体插画减少了长段文字的依赖。
- **空间组织**：窄侧栏与宽内容区形成“索引—内容”结构，横向对应降低分类查找成本。

## 五｜D｜数据/信息架构

1. 总主题：地球生命的发展。
2. 一级分类：地质年代大类。
3. 二级分类：具体地质时期。
4. 内容层：各时期对应的生物群像、生态环境和地貌场景。
5. 视觉索引：左侧分组标签与横向分隔线。

其核心架构是“上位分类—下位时期—对应场景”，而非以连续时间刻度为中心的事件序列。

## 六｜E｜视觉叙事架构

读者先通过左侧导航识别上位年代类别，再定位其下的具体时期，随后横向阅读右侧生命场景。纵向排列使分组之间带有历史先后感，但真正的阅读线索是左侧层级标签和右侧内容的对应关系。每个分区可被单独理解，也可在整体上比较不同分类组的生命场景。

## 七｜可迁移设计方法

1. 当内容具有明确的上位类别与下位子类时，可使用固定侧栏呈现层级标签。
2. 让每个子类与其内容区严格对齐，建立清晰的归属关系。
3. 通过侧栏分段、缩进、色块或括号区分一级与二级类别。
4. 主体图像可用于解释类别特征，但应避免让图像丰富度暗示数量或重要性。
5. 如果类别本身有时间先后，可将时间作为辅助索引，不必把整个版面强制设计成比例时间轴。

## 八｜类型边界与待核实

- 本案例包含地质年代顺序，但主要视觉结构是“年代大类—具体时期—对应场景”的层级关系，因此主归类为层级型。
- 当前图像未显示明确的时间比例尺，不能依据分区高度推断各时期的真实持续时间。
- 具体年代标签、物种身份及生态组合需要高清原图或原始资料核对。
- 作者、来源与版权信息尚未提供。

## 十｜01 类别与 02 标签归档

- **01 主类别**：层级型（H）。上位地质年代分组、下位具体时期及其对应生命场景构成主导结构。
- **次要特征**：年代先后是辅助顺序，不是按比例时间轴。
- **02 现有标签**：待核对正式标签清单；候选描述为“侧栏分类索引 / 分层分类 / 图文对照”，暂不登记为正式标签。
- **分类依据**：侧栏以包含/归属关系组织分类，右侧场景与分类条目横向对齐。

## 十一｜制作方法与流程（推测与观察分开）

1. 收集地质年代分组、时期名称及代表性生命/生态素材（推测）。
2. 建立“年代大类—具体时期—对应生命场景”的分类表（由版面结构推导）。
3. 选择每个时期的代表性生物和生态环境，制作或整理插画（推测）。
4. 使用左侧固定栏呈现分类层级，右侧按行配置场景，并通过横向对齐和分隔线建立对应关系（图面可观察）。
5. 校对时期名称、年代范围、物种身份及图像来源（必要步骤，实际执行情况未知）。

具体软件、数据来源和插画制作工具未知。
