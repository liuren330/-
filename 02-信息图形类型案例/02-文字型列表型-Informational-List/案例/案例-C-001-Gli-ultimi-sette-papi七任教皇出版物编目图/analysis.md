# 案例 C-001｜Gli ultimi sette papi：七任教皇出版物编目图

- **主类型**：编目型信息图形
- **辅助组织维度**：时间序列、人物分类、统计比较
- **图面标题**：Gli ultimi sette papi（最近七任教皇）
- **图像记录**：用户上传文件 `图片4(1).png`，1280 × 631 px。原始作者、出版物出处和版权信息尚未核实。
- **主题**：七任教皇的任期、年度出版物及出版语言。

## 一、客观观察

画面以大面积半圆/环形放射结构为主体。顶部和环形外缘标示年份及教皇任期信息；不同颜色的弧段区分教皇。内侧放射状柱形/条形从中心向外延伸，配合符号表达年度出版物相关数据。左侧设置阅读说明、教皇与出版物图例、语言缩写及数量尺度；右侧列出教皇方济各时期的出版物条目；底部以按教皇分组的菱形符号矩阵比较不同语言的出版情况。中心区域还有按教皇归纳的放射状汇总图形。

标题、图例可辨认出七任教皇包括 Pius XII、Giovanni XXIII、Paolo VI、Giovanni Paolo I、Giovanni Paolo II、Benedetto XVI 和 Francesco。图面同时呈现任期年份、出版物类型、出版物数量及语言维度。

## 二、A｜基本数据逻辑

- **基础条目**：教皇、出版物记录、年度统计记录。
- **主编目对象**：七任教皇及其任期内的出版物集合。
- **分类维度**：教皇身份、出版物类型、语言。
- **时间维度**：任期和出版年份为条目提供时间索引；时间是组织和比较出版物的一个维度，并非唯一主逻辑。
- **数量维度**：按年或按教皇汇总的出版物数量，用于比较不同条目/分类的规模。
- **推测的数据模型**：
  - `Pope(pope_id, name, pontificate_start, pontificate_end)`
  - `Publication(pub_id, pope_id, year, title, type, language)`
  - `AnnualCount(pope_id, year, publication_type, count)`
  - `LanguageCount(pope_id, language, count)`
  以上是从可见版面推导的数据结构，不代表原始数据表。

## 三、B｜统计图形与计算方式

- **环形/弧形时间带**：把年份和教皇任期组织在同一圆弧坐标中。
- **放射状条形/柱形**：以长度表达年度出版物数量或相关计数。
- **中心汇总图形**：将教皇维度的出版数据汇总呈现。
- **底部矩阵/符号图**：按教皇和语言分组比较出版语言分布；菱形大小/内部编码需结合原图例读取。
- **条目清单**：右侧文字列表呈现出版物名称或出版记录。
- **计算方式**：可能涉及按教皇、年份、出版类型和语言进行分组计数、分类汇总及比较。具体统计口径、去重规则和各符号代表的计数单位应以原始数据说明为准。

## 四｜C｜视觉编码

- **角度/环带位置**：建立年份在圆周上的位置关系。
- **弧段颜色**：区分不同教皇/任期。
- **放射条长度**：表达数量差异。
- **符号形状**：区分出版物类型或事件标记，需参照左侧图例。
- **底部菱形矩阵**：将语言维度转化为可横向扫描的符号序列。
- **文字与图例**：左侧说明如何读图；右侧列举出版物条目；底部标签提供教皇与语言的交叉索引。
- **层次关系**：主体统计图、侧边说明/列表、底部比较矩阵构成三个互补阅读区域。

## 五｜D｜数据/信息架构

1. 总主题：最近七任教皇。
2. 人物索引：七任教皇及任期。
3. 时间索引：任期内各年份。
4. 出版物编目：年度记录、出版类型及出版条目。
5. 属性比较：语言类别及各教皇时期的语言分布。
6. 图例与来源说明：解释计数单位、颜色、符号和数据来源。

可概括为“人物条目—时间索引—出版物记录—类型/语言属性—数量汇总”。

## 六｜E｜视觉叙事架构

读者先从标题和图例理解对象范围与编码方式，再沿半圆环带定位七任教皇及其任期；放射状数量图形用于比较各年度或各任期的出版活动；右侧列表展示具体出版物条目；底部语言矩阵进一步比较不同教皇时期的出版语言。阅读路径不是单向时间故事，而是围绕同一组教皇/出版物条目在多个维度间切换。

## 七｜可迁移设计方法

1. 对具有共同身份字段的条目集合，可用人物/机构作为主索引，再附加时间和属性维度。
2. 当时间是重要字段但不是主分类关系时，可把时间做成环形或带状索引，不必把整体归为编年叙事。
3. 统计图形可以嵌入编目系统：条目清单负责识别对象，图形负责比较属性。
4. 图例应明确区分“对象身份颜色”“类别符号”和“数量长度/面积”，避免编码语义混用。
5. 多维版面需要分区：主统计、条目详情、交叉属性矩阵各自承担明确任务。

## 八｜局限与待核实

- 细小图例文字及部分环形标注受图像分辨率限制，需高清原图核对。
- 年度放射条的精确计数单位、出版物类型符号及底部菱形矩阵的数值映射需进一步核实。
- 右侧列出的出版物看起来聚焦于2018年教皇方济各的著作/文件，但具体字段和收录范围需原始来源确认。
