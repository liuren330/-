# Gestalt格式塔视觉组织原则研究库

本目录研究视觉感知如何组织元素、形成群组、区分对象与背景，并将理论用于信息图形设计分析与实践。

## 原则数量与分类说明
格式塔原则没有全球统一、固定的数量。权威综述将经典分组原则（接近、相似、共同命运、连续、闭合、对称、平行）与较新的组织线索（同步、共同区域、元素连接、统一连接）一并讨论，同时另行讨论图形—背景组织。为便于系统研究，本库采用**13项工作条目**：9项核心条目与4项扩展条目。此数量是本项目的管理口径，不代表学界唯一标准。

## 核心原则（9项）
1. 接近律 Proximity：距离较近的元素倾向被看作一组。
2. 相似律 Similarity：形状、颜色、尺寸、方向等属性相似的元素倾向被归为一组。
3. 连续律 Good Continuation：视觉倾向沿平滑、连贯的路径组织轮廓与元素。
4. 闭合律 Closure：不完整轮廓可能被知觉补全为完整形状。
5. 图形与背景 Figure–Ground：视觉场被组织为突出的对象及其背景。
6. 共同命运律 Common Fate：朝相同方向运动或同步变化的元素倾向被视为相关。
7. 共同区域律 Common Region：被同一边界包围的元素倾向被归为一组。
8. 对称与秩序 Symmetry and Order：对称、规则结构更容易被组织为整体。
9. 简洁性／良好形式 Prägnanz：知觉倾向形成相对简单、稳定、规则的组织形式。

## 扩展组织因素（4项）
10. 平行律 Parallelism：方向平行或具有相同方向关系的元素可能被组织为一组。
11. 同步律 Synchrony：同时发生变化的元素容易被感知为相关。
12. 元素连接律 Element Connectedness：被线条等明确视觉连接直接相连的元素容易被看作整体。
13. 统一连接律 Uniform Connectedness：形成统一视觉连接单元的元素容易被感知为相关整体。

## 重要概念边界
- Prägnanz常是统摄性的组织倾向，不宜简单视为与接近律同层级的单一规则。
- Figure–Ground是对象与背景的分化问题，不完全等同于元素群组原则。
- Common Region、Element Connectedness、Uniform Connectedness在现代研究与设计文献中有讨论，但彼此概念存在交叠。
- Parallelism、Synchrony在不同文献中的归类与独立地位并不完全一致。
- 以上线索会相互作用，不是彼此排斥的固定公式。
