# 02｜主题内容分析

目标：把选题拆成可回答的问题、概念关系和可视化任务，与大模型协作提出分类建议，再由人核验。

步骤：1. 定义主题边界、核心问题和受众需求。2. 拆分实体、属性、事件、地点、时间及关系。3. 判断主信息组织类型：编年、层级、编目、字母表、地理或混合。4. 判断表达形式：词云、文字型、照片型、地图、时间轴、统计图表等。5. 判断视觉风格：平面、照片、插画、手绘、混合。6. 判断设计方法标签：ISOTYPE、图标系统、摄影叙事等。7. 输出主标签、次标签、理由、替代方案和误读风险。

保存大模型输入资料、提示词、模型建议、事实核验结果与最终人工决策。模型不能代替来源核验，不得虚构数据。

建议产出：主题内容结构.md、标签判定表.csv、大模型讨论与人工核验.md。
