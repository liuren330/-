# 06｜视觉编码

本阶段偏重设计表达：把数据与叙事关系转译为点、线、面、体、文字、图像、色彩和统计图形的视觉规则。

- 点：位置、数量、节点、标记；明确位置是否对应真实坐标。
- 线：连接、路径、时间、流向、边界；区分方向、权重与关系类型。
- 面：区域、分组、面积量化、底色分区；面积映射需有比例依据。
- 体：体积、层叠、空间结构；避免无依据的3D夸大量值。
- 色彩：类别、顺序、发散、状态；建立色板、对比度与色觉适配规则。
- 字体与排版：字体、字号、字重、行距、字距、对齐、阅读层级。
- 图像与图形：照片、插画、图标、纹理、图例和注释；记录来源及许可。
- 统计图形：条形、折线、散点、面积、矩阵、地图等；图形类型须匹配数据关系。
- ISOTYPE：标准化符号、符号单位、重复数量、图例和舍入规则。
