# 04｜基础数据集构建

## 原子数据规则

一列只代表一个字段，一格只允许一个数据值。值可以是名义数据、量化数据、日期、单个图像文件引用或单段文本；但不能在一个单元格中放多个名称、多个数值、多个坐标或多个标签。

正确示例：一行一个地点，地点名称、纬度、经度分别独立成列。错误示例：把多个城市塞入同一单元格，或把纬度和经度合并成一个坐标字段。

## 数据表建议

- 主表：每行一个分析对象/事件/记录，设置唯一ID。
- 关联表：多对多关系另建表，以外键关联，避免把多个值拼接在单元格中。
- 图像表：每张图像独立一行，记录文件路径、来源、作者、许可、拍摄/发布日期。
- 文本表：每条摘录独立一行，记录来源和页码/段落。

必须配套数据字典、来源字段、单位/格式、采集日期、缺失值规则、清洗日志和版本号。
