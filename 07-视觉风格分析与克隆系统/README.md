# 07｜视觉风格分析与克隆系统

> 独立的视觉风格研究与生成方法库。研究如何从参考图像中提取可复用的视觉生成机制，建立结构化风格模型，并支持跨主题迁移、提示词编译和质量校准。

## 项目定位

本目录承接此前解析的16份设计理论、视觉语言、风格克隆、专项应用与多图叙事资料。它与 01–06 并列，作为信息图形知识库中的第七个独立研究库；**不属于信息图形五种基础组织逻辑，也不属于02的市场化表现标签**。

- 01：信息图形数据逻辑
- 02：信息图形类型案例
- 03：ISOTYPE信息图
- 04：统计图形分析
- 05：Gestalt视觉组织原则
- 06：具体主题信息图形设计
- **07：视觉风格分析与克隆系统**

## 核心目标

1. 精准识别参考图像中的视觉风格特征与生成规则。
2. 将分析结果规范化为可复用的 Style Model / JSON。
3. 分离 Style（如何表现）与 Theme（表现什么），支持主题替换而尽量保持风格稳定。
4. 从同一份规范化模型编译多种提示词格式。
5. 通过生成测试、偏差诊断和校准持续提高一致性。

核心理念：克隆的是视觉生成机制，而不只是复制单张图像的表面元素。

## 当前规范基线

**V2.0 规范整合版**。SC-IMG作为运行架构主骨架，VSCF作为前代框架与术语来源。八个视觉分析维度负责观察与归档；五个总控、十三个分系统负责运行控制。

## 重要边界

当前已完成资料解析与规范整合；真实参考图端到端分析、四种提示词一致性、跨模型迁移及专项适配实测仍需继续验证。未完成的测试不得标记为已通过。
