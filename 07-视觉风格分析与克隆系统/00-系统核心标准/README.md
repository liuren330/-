# 00｜系统核心标准

## 系统目标
从参考图像中提取可复用的视觉生成机制，形成规范化 Style Model，支持风格迁移、主题扩展、跨媒介应用、提示词编译和质量校准。

## 六个系统模块
1. 风格识别与解构
2. 风格模型构建
3. 提示词生成引擎
4. 风格应用引擎
5. 生成测试与风格校准
6. 风格资产库

## 三种启动入口
- 文档入口：上传系统文档，检查版本并加载模块。
- 仓库入口：读取入口说明、核心标准、数据契约、提示词规范、迁移和测试规范；按依赖加载。
- 记忆入口：记忆只保存系统名称、启动口令、核心原则、版本和恢复位置；完整细则必须从仓库或文件恢复。

三个入口必须进入同一引擎，不能产生规则或 JSON 结构分叉。

## 启动状态
- READY：必需模块完整且版本一致。
- PARTIAL：部分模块缺失，可做探索性分析，不能声称完整规范交付。
- BLOCKED：核心标准缺失或无法读取来源。
- MEMORY_ONLY：只有记忆摘要，不可假称完整加载。

## 设计原则
- 设计者负责目标定义、质量判断与校准；AI承担分析、生成和执行。
- 视觉语言由词汇、语法、语境构成。
- 不可观察的信息不得编造。
- 单张图像的偶然特征不能轻易判定为高置信度风格不变量。
- 通用 Style Model 与平台专属参数分离。
