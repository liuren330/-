# 05｜多图一致性与叙事控制

适用范围：多图系列、角色设定、场景连续性、脚本/分镜、连续帧与视觉叙事。

## 五个风格一致性锚点
- line_quality：线条质量与线性语言
- color_palette：色彩体系
- light_logic：光线逻辑
- space_treatment：空间处理
- detail_density：细节密度

五个锚点按任务与风格启用，不是所有风格的强制字段。

## 主体与角色
通用主体字段使用 subject；character 是人物专项扩展。人物一致性可记录脸型、眼睛、头发、标志性特征及禁止变化项。

## 分镜与叙事
关注叙事弧线、脚本、分镜、景别、镜头语言和帧间关系。

## 三层校验
1. 叙事结构是否成立
2. 风格一致性是否稳定
3. 角色/主体/场景是否连续

系列任务共享 Style Profile，每张图建立独立 Image Task 和 Image Review，保存逐图差异。
