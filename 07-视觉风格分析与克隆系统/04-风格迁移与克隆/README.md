# 04｜风格迁移与克隆

## 核心概念
- **Style**：如何表现，包括视觉形式、组织规则、材质语言、色彩逻辑和图形语法。
- **Theme**：表现什么，包括主体、对象、题材、语义和叙事内容。
- **Theme Adapter**：将新主题映射到既定风格规则。
- **Medium**：输出媒介或载体。
- **Task**：画幅、用途、文字、数量等本次任务要求。
- **Backend**：实际生成模型、平台和工具参数。

## 三类风格规则
- invariant：风格不变量，跨主题应保持。
- variable：风格可变参数，在规定范围内调整。
- constraint：禁止项或边界条件，防止风格漂移。

另独立记录三个规则维度：
- 要求类别：style / content / presentation
- 变化属性：core / project_locked / conditional / free
- 执行级别：must / should / may

## 五种应用模式
1. 原图复刻
2. 同主题扩展
3. 跨主题迁移
4. 跨媒介迁移
5. 风格校准

## 迁移原则
保持风格不变量；变量只在范围内变化；约束不被新主题覆盖；分别评估主题语义准确性与风格一致性；不把特定样例中的数值比例推广为通用常数；无证据参数标未知或低置信度。

## 提示词编译
输出四种格式：中文 JSON、English JSON、中文简易提示词、自然语言提示词。四种格式必须从同一份规范化 Style Model 派生，确保字段与规则一致。
