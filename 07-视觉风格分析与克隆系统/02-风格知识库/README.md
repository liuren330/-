# 02｜风格知识库

本模块保存设计流派、插画史、视觉叙事原型和参考案例知识。历史风格名称是研究索引，不应被当作无需分析即可套用的固定 Prompt 标签。

## 插画史六个观察坐标
1. 版画与黑白叙事
2. 黄金时代装饰插画
3. 现代主义几何化
4. 美国叙事插画
5. 日本视觉语言
6. 当代数字插画

## 来源资料中的风格叙事原型
古典主义、包豪斯、表现主义、极简主义、Art Deco、纪实主义、赛博朋克、当代东方美学。

其他涉及流派：国际主义、苏联构成主义、当代数字风格。

## 分析原则
风格是视觉身份与叙事立场，不只是表面装饰。应分析其形式特征、视觉语法、历史/文化语境、情绪倾向和叙事目的。

## 参考资料记录
可获得时记录作者/机构、作品名称、年代、媒介、出处、访问链接和使用权限。未核验的作品细节或来源不得编造。
