## 整合决策
- SC-IMG作为V2.0运行架构主骨架；VSCF保留为前代框架与术语来源。
- 八个视觉分析维度负责观察与归档；五个总控、十三个分系统负责运行控制。
- Style / Theme / Task / Medium / Backend 分离。
- 通用规则分类为 invariant / variable / constraint。
- 要求类别、变化属性、执行优先级独立记录。
- 通用主体使用 subject；character 是人物专项扩展。
- 五个一致性锚点按任务启用。
- VSCF特定比例不作为通用常数。
- 核心记录建议为 style_profile、image_task、image_review。
- 四种提示词输出从同一规范化 Style Model 派生。
- 平台工具参数进入适配层，不进入通用风格核心。

## 版本保留原则
Markdown与DOCX同主题资料作为平行版本保留。发现差异时记录来源、原文位置、差异类型和最终决策；未经确认不得覆盖或删除原始来源。
