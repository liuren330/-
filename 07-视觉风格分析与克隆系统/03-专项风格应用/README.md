# 03｜专项风格应用

专项适配器建立在通用 Style Model 之上，不另建互不兼容的核心体系。

## 字体风格适配
独立记录字形骨架、笔画粗细与对比、字面比例、字距与行距、衬线/无衬线特征、笔形与端点、可读性、文字层级，以及文字在构图中的角色。文字内容与字体风格分离。

## 海报风格适配
结合版式、标题层级、图文关系、信息密度、视觉锚点和传播目的。来源资料涉及包豪斯、国际主义、苏联构成主义、Art Deco、表现主义、极简、赛博朋克、东方美学、纪实和当代数字风格。

## 插画风格适配
结合插画史坐标、线条、形态、色彩、材质、叙事方式、角色与场景设计。

## 校准原则
优先单变量调整，并记录调整前后的参数与结果，避免多个变量同时变化而无法定位原因。
