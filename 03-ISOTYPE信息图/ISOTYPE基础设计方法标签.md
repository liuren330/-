# ISOTYPE｜基础设计方法标签与分析框架

> 标签性质：基础设计方法 / 视觉表达方法。此文档归属03-ISOTYPE信息图专项项目，不是02目录中的信息图形类型标签。

## 1. 标签定义
ISOTYPE（International System of Typographic Picture Education，国际文字图像教育系统）是一套以标准化图像符号组织、转换和传播社会事实的视觉教育与信息表达方法。重要设计思想包括：用可识别的图像符号代表对象；通过重复符号及其数量表达统计量；建立统一的符号语法和阅读规则；将复杂数据转化为可理解的视觉叙事。

## 2. 为什么不归为信息图形类型
信息图形类型回答“信息按什么逻辑组织”或“视觉上如何呈现”；ISOTYPE回答“如何把信息转译成视觉符号”。两者属于不同维度。地理型、编目型或编年型信息图都可以采用ISOTYPE方法。

## 3. 方法识别字段
| 字段 | 内容 |
|---|---|
| 方法名称 | ISOTYPE |
| 中文名称 | 国际文字图像教育系统 / 图像统计符号方法 |
| 方法层级 | 基础设计方法 |
| 英文关键词 | ISOTYPE, pictorial statistics, picture language |
| 主要视觉单位 | 标准化人物/物件图像符号 |
| 主要编码方式 | 符号重复、符号单位值、阵列、图像语法 |
| 适配信息 | 数量、社会统计、分类比较、过程说明、公共教育 |
| 可组合类型 | 编年型、层级型、编目型、字母表型、地理型及混合型 |
| 使用限制 | 必须说明单个符号代表的数值；避免图标大小与数量同时变化造成误读 |

## 4. 视觉设计检查点
- 图像符号是否标准化、可辨识且语义一致？
- 一个符号代表几个对象/多少数量，是否明确写出？
- 是否用重复符号数量表达数值，而非随意放大图标面积？
- 不同群体/类别是否使用稳定、尊重且不歧视的符号表达？
- 图例、单位、数据来源、时间范围和统计口径是否完整？
- 数据不能整除符号单位时，是否解释半符号、比例符号或舍入规则？

## 5. 适用场景
人口与社会统计、职业/生产/资源比较、公共卫生与教育信息、历史过程、地理分布，以及需要降低文字阅读门槛的公共传播项目。

## 6. 与其他视觉方法的关系
ISOTYPE可以与地图、时间轴、分类矩阵、流程图、文字叙事、摄影等共同使用。采用图标不自动等于采用ISOTYPE；需具备系统化符号设计、明确的单位规则和可解释的视觉语法。
