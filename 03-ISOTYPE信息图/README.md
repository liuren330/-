# 03-ISOTYPE信息图

本目录是ISOTYPE（International System of Typographic Picture Education，国际文字图像教育系统）的独立专项研究项目。

**项目定位：基础设计方法研究，而非信息图形类型研究。** ISOTYPE不计入02目录的17种表现类型，也不属于01目录中的T/H/C/A/G五大信息组织逻辑。它研究如何通过标准化图像符号、明确的符号单位和一致的视觉语法，将统计与社会事实转译为易于理解的视觉表达。

## 研究内容
1. **方法定义与历史脉络**：研究Otto Neurath、Gerd Arntz、Marie Neurath及Isotype Institute的实践与发展。
2. **符号系统**：标准化图像符号的设计、识别、语义一致性与文化适切性。
3. **数量表达**：符号重复、单位值、阵列、比例符号及舍入规则。
4. **视觉语法**：符号、图例、版式、阅读顺序与叙事结构。
5. **数据转译**：从原始统计数据到图像符号表达的转换流程。
6. **案例研究**：记录原始出版物、作者、年代、馆藏或稳定来源链接，并分析其方法应用。

## 与信息图形类型的关系
ISOTYPE是一种设计方法，可以与编年型、层级型、编目型、字母表型、地理型以及混合型等不同信息组织逻辑或表现形式结合。单纯使用图标并不自动构成ISOTYPE；应具备系统化符号设计、明确单位规则和可解释的视觉语法。

## 研究与引用原则
优先使用原始出版物、馆藏目录、机构档案和可核验的历史资料。记录具体出版物、页码或稳定链接；区分史料事实、研究者解释与待验证判断。未经许可不重新分发受版权保护的原图。
